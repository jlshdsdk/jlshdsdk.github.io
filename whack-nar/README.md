# 打地鼠 · 纳尔篇 🐾

一只名叫**纳尔**的奶牛猫在线求拍。HTML + CSS + 原生 JavaScript 实现的打地鼠小游戏，
手机、平板、电脑打开链接即玩，无任何第三方依赖。

## 纳尔是谁

纳尔是一只奶牛猫（黑白双色）：背部和头顶是大块墨黑，脸中央一块白色倒 V 面具，
粉色鼻子，圆圆的黄绿色眼睛，四只脚是白色「小袜子」，尾巴通体黑色。
体型微胖、脖子短、耳朵大而尖，性格好奇又记仇——**被拍中会委屈，但很快又探头来看**。
游戏里的纳尔全部使用它的真实照片（`assets/nar/`），CSS 手绘奶牛猫仅在照片缺失时兜底。

## 玩法说明

- 3×3 共 9 个洞，纳尔会从随机洞口探出，在它缩回之前点它/拍它。
- **普通纳尔** +10 分，停留约 1 秒；**快速纳尔** +25 分，头顶有闪电标记，停留约 0.55 秒，
  漏掉它扣 1 条命；**装睡纳尔**不能拍——误拍扣 15 分并扣 1 条命，
  耐心等它睡醒睁眼，就会变成可以拍的普通纳尔。
- **连击**：2 秒内连续命中累积连击，界面显示 `COMBO ×N`；
  每 5 连击触发「纳尔暴走」——9 个洞同时冒头 0.6 秒，命中一个 +50 分。
- **生命**：初始 3 条命（❤️❤️❤️），扣完游戏结束。
- **难度**：每 15 秒进入下一关，出洞更快、停留更短、快速纳尔更多；三关后进入无尽模式。
- 右上角 🔊 可静音（音效由 Web Audio 现场合成，刷新后保留设置）；
  历史最高分保存在本地，刷新不丢。
- 结算页可点「保存战报」，用 canvas 合成一张图片下载分享。

## 图片替换方法

所有照片在 `assets/nar/` 目录，固定命名、即换即用：

| 文件 | 用途 |
|---|---|
| `peek-1.webp` / `peek-2.webp` | 探头照（只露头顶、耳朵和眼睛） |
| `up-1.webp` / `up-2.webp` | 升起照（整只猫或大半身，正面） |
| `hit-1.webp` | 被拍中时的呆滞/委屈表情 |
| `sleep-1.webp` | 装睡照（闭眼趴着/打呼） |
| `rage-1.webp` | 暴走照（炸毛或瞪眼，连击奖励事件用） |
| `avatar.webp` | 头肩特写，开始页/结算页/战报图用 |
| `decor-1.webp` | 庭院篱笆上远处偷看的纳尔（装饰） |

替换时注意：单张压缩到 200KB 以内、最长边不超过 600px、清除 EXIF 元数据后再提交；
命名保持一致，页面无需改任何代码。任何一张图加载失败，游戏会自动退化为
纯 CSS 绘制的黑白奶牛猫，照常可玩。

## 技术说明

- 入口 `index.html`，样式 `styles.css`，逻辑 `game.js` 三个文件分工
  （相比单文件：状态机、调度器、音效模块边界清晰，便于后续维护；
  站点部署在 GitHub Pages 子目录，多文件无额外请求成本）。
- 全部资源使用相对路径 `./assets/nar/...`，部署在 `/whack-nar/` 子目录不会 404。
- 统一调度器 `Scheduler` 管理所有计时器（出洞、停留、关卡、连击窗口）：
  页面切走时自动暂停，回来时把未来任务的截止时间整体后移，不会一次性冒出一堆纳尔。
- 音效为 Web Audio API 现场合成（啪 + 喵滑音 / 呜 / 铃声），无任何外链音频。
- 不引用第三方字体、图标库或 CDN；图形由真实照片 + CSS/SVG 完成。

## 本地运行

直接双击 `index.html` 即可，或起一个静态服务：

```bash
cd whack-nar
python -m http.server 8080
# 打开 http://localhost:8080
```
